**Pergunta:** Qual o prazo de devolução para carga perigosa?

**Resposta:**

Com base no POL-001 (seção 3.2), cargas perigosas classificadas nas classes 1 a 6 da ANTT **não são elegíveis para devolução pelo processo padrão**. Isso inclui explosivos, gases, líquidos inflamáveis, sólidos inflamáveis, oxidantes, peróxidos, substâncias tóxicas e infectantes, conforme a Resolução ANTT nº 5.947/2021.

Para esses casos, o cliente deve entrar em contato com o setor de **Gestão de Riscos (ramal 4500)** para tratamento individual.

**Fonte:** POL-001 — Política de Devolução de Mercadorias, v3.1, seção 3.2

**Observação:** Não há prazo alternativo definido na documentação. O caso deve ser encaminhado obrigatoriamente ao setor de Gestão de Riscos.

**Pergunta:** Meu cliente é Gold, qual o SLA de resolução?

**Resposta:**

Com base no SLA-2024 (seção 2), os SLAs de resolução para clientes Gold são:

| Tipo de chamado | SLA de Resolução |
|----------------|-----------------|
| Chamados gerais | Até 24h úteis |
| Incidentes críticos | Até 4h (sem pausa fora do horário comercial) |

O relógio de SLA para chamados gerais pausa fora do horário comercial (08h–18h, dias úteis). Para incidentes críticos de clientes Gold, o relógio não pausa.

**Fonte:** SLA-2024 — Tabela de SLA por Tipo de Cliente, v2024.1, seções 2 e 5

**Observação:** Para identificar se o chamado é um incidente crítico, consultar os critérios da seção 3 do mesmo documento.

**Pergunta:** Quanto custa o frete para 600kg para Manaus?

**Resposta:**

Com base no PROC-042-v2 (seções 2 e 2.1), é possível identificar os parâmetros aplicáveis, mas não é possível calcular o valor final sem a tarifa base.

| Parâmetro | Valor aplicável |
|-----------|----------------|
| Fator de peso (500kg a 1.000kg) | 1.0 |
| Multiplicador regional — Norte (Manaus) | 1.8 |

A fórmula a ser aplicada é:

> **Valor do frete = Valor base × 1,8 × 1,0**

O Valor base corresponde à tarifa publicada na tabela mensal de fretes, que não está presente na documentação consultada.

**Fonte:** PROC-042-v2 — Procedimento de Cálculo de Frete Especial, v2.0, seções 2 e 2.1

**Observações:**
- Consultar a tabela mensal de fretes para obter o valor base antes de informar ao cliente.
- Verificar histórico do cliente: a partir de 8 fretes especiais/mês, aplica-se desconto de 5% sobre o multiplicador regional.
- Se a carga for perigosa, não utilizar esta fórmula — consultar PROC-043.
